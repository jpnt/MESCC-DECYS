Notes on each dump:
- *PROGMEM.bin* holds Dan/Alan chat, the EULA, the menu strings, the credential table and the two base64 crypto blobs.
- *SRAM.bin* a runtime image; the PROGMEM string block is mirrored.
- *EEPROM.bin* all padding ; ~strings~ yields void.

The second maintenance password is at *0x4474 (17524)*; the developer password

password.


* Q: How long are the base64 blobs?
Two base64 blobs are hardcoded in the chat comments:

- *RSA private key* (~MIIEpA...~): *1592* base64 chars -> 1192 raw bytes.
- *Signature* (starts ~b+gJJK...~): *344* base64 chars -> 256 raw bytes.

#+begin_src sh
  > python3 -I -c '
  import base64
  d=open("PROGMEM.bin","rb").read()
  for tag in (b"MIIEpAIBAAKCAQEA", b"b+gJJKG56gAz"):
      i=d.find(tag); j=d.find(b"\"", i); blob=d[i:j]
      print(len(blob),"chars ->",len(base64.b64decode(blob)),"bytes")'
  1592 chars -> 1192 bytes
  344 chars -> 256 bytes
#+end_src
