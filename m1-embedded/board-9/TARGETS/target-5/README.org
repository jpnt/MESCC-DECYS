* Q: Why is a short rainbow table enough here?
MD5 is deterministic, so a precomputed table reverses any digest by lookup
instead of brute force. The table is small only because the keyspace is: every
entry is a fixed 53-char string with the known =cnc= prefix, ~100000 in all, so
the attacker hashed that predictable set once.
