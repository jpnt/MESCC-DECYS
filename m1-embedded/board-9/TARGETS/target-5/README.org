*** Why a short rainbow table is enough here
MD5 is deterministic: the same input always maps to the same
digest, so a precomputed hash table reverses any digest by lookup
instead of brute force. The table only has to be "short" because the password
keyspace is snamll, not arbitrary. Every one of the ~100000
entries is a fixed 53 char string with the known =cnc= prefix.
The attacker only had to hash that small, predictable set once.
